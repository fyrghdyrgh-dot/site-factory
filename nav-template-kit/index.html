template pack

基于 5 个 AI 导航站抽出来的 3 套页面模板

这套模板不是简单换色，而是按参考站的共性拆成 3 种更易复用的页面结构：搜索导航型、分类目录型、媒体门户型。它们都保留了目录站的高密度信息组织方式，但去掉了难维护的杂乱堆叠。

适合 AI 工具导航 适合出海工具站 适合设计资源导航 适合后续接 family-nav
3可预览模板
5参考站点
1共享样式底座

模板怎么分

模板一：搜索导航型 强调 Hero 搜索、热门推荐和入口分发。
模板二：分类目录型 强调左侧导航、分类锚点、长列表与批量卡片。
模板三：媒体门户型 强调推荐流、资讯感、排行榜和专题混排。
模板入口

先打开预览页看结构，再决定要不要把某一套接进现有导航站生成器。

T1
搜索导航型
参考 kjdaohang / 部分 ai-bot 首页入口

适合把“搜索 + 热门推荐 + 分类卡片”放在最前面，用户一进站就能开始找工具。

Hero 搜索 热门推荐 快速分流
打开模板 适合新站首页
T2
分类目录型
参考 uisdc / aigc.cn / ai-bot 分类页

适合工具量很多、分类层次较深的导航站，用锚点和侧边栏稳住浏览效率。

左侧目录 分类密集 可扩容
打开模板 适合大站
T3
媒体门户型
参考 amz123 / aigc.cn 的资讯与推荐混排

适合既有导航卡片，又想混入热榜、专题和资讯入口的站点，更像“媒体化导航站”。

热榜 资讯混排 商业推荐位
打开模板 适合内容站
