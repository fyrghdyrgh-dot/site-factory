使用步骤

  1. 先保留原始请求和签名字段
  2. 再看返回状态码和超时情况
  3. 比对重试次数和幂等处理
  4. 最后用同 payload 做一轮重放

FAQ

Webhook 回调复核页 常见问题

为什么要保留原始请求？

没有原始请求，很难区分是签名串变化还是你本地逻辑处理异常。

幂等一定要做吗？

如果第三方会重试，幂等处理几乎是必须项。
