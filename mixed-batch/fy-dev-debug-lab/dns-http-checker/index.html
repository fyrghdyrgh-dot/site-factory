FAQ

域名与 HTTP 状态检查 常见问题

DNS 生效了为什么页面还是旧的？

通常和浏览器缓存、CDN 缓存或地区传播延迟有关。

HTTP 200 就代表没问题吗？

不一定，还要检查页面内容、关键接口和跳转是否符合预期。
