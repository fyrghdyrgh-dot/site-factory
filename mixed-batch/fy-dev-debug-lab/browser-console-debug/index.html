使用步骤

  1. 先看 Console 第一条错误
  2. 再切到 Network 看失败请求
  3. 确认资源、接口和脚本哪个先异常
  4. 最后结合页面操作路径复现问题

适合谁用

  • 页面白屏排查
  • 脚本错误定位
  • 资源加载异常

输入与输出

输入：报错截图、控制台日志、复现步骤

输出：排错顺序、异常范围判断

FAQ

浏览器控制台排错顺序 常见问题

Console 里很多报错先看哪个？

优先看最早出现、最接近主流程的错误，而不是数量最多的提示。

Network 全是 200 还可能有问题吗？

有可能，接口内容错误、脚本执行异常和状态同步问题都可能发生。
