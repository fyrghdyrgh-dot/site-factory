# 参考站相似性总结

参考站：

- `https://www.kjdaohang.com/`
- `https://www.amz123.com/ai`
- `https://ai-bot.cn/`
- `https://www.aigc.cn/`
- `https://hao.uisdc.com/ai/`

## 共同点

1. 首页一定先给“快速进入”的理由

- 要么是大搜索框，要么是热门分类，要么是编辑精选。
- 用户进入后不需要理解网站逻辑，先能点到东西。

2. 都不是单纯的瀑布流

- 页面都在做人工组织，而不是只把链接堆起来。
- 常见结构是：热门推荐 -> 分类块 -> 更多分类 / 专题 / 榜单。

3. 卡片信息密度都很高

- 基本都是“名称 + 一句话描述 + 标签/语言/推荐标记”。
- 好的导航站不会让卡片只有标题，描述承担了筛选作用。

4. 分类是核心，而不是附属

- `ai-bot.cn`、`aigc.cn`、`hao.uisdc.com/ai/` 都有明显的大分类结构。
- 这说明导航站要长期维护，分类必须是一级结构。

5. 运营位非常多

- 热门推荐、最新收录、专题、榜单、广告位、编辑推荐都很常见。
- 导航站本质上不是纯工具库，而是“工具分发 + 运营入口”。

6. 首页都在做“降低选择成本”

- 不是让用户自己全站翻，而是提供热门、最新、推荐、专题这些捷径。
- 所以模板设计的关键不是“放多少卡片”，而是“怎么分层给入口”。

## 差异点

### `kjdaohang`

- 更偏搜索入口和总门户。
- 首屏口号感强，强调“快速找到优质工具”。
- 适合做搜索导航型首页。

### `amz123 / ai`

- 更偏资讯站和行业站的专题页。
- 工具之外还有媒体化推荐和较明显的商业化入口。
- 适合做门户型模板。

### `ai-bot.cn`

- 结构最像“大型 AI 工具目录站”。
- 有热门、最新、分类、教程、快讯等多个层次。
- 适合做大分类目录模板。

### `aigc.cn`

- 商业推荐位非常重，分类也很多。
- 站点更像“工具分发站 + 专题运营站”。
- 适合做带广告位和专题推荐位的模板。

### `hao.uisdc.com/ai/`

- 视觉上最干净，分类与卡片秩序感最好。
- 很适合抽成“高质量目录模板”。
- 适合做设计感更强、但仍是高密度信息布局的模板。

## 这次抽出的 3 套模板

1. `template-search-hub.html`

- 适合新站首页
- 强调搜索、热门推荐和场景入口
- 参考：`kjdaohang`、`ai-bot` 首页入口区

2. `template-category-directory.html`

- 适合大目录站
- 强调左侧目录、分类锚点和长列表
- 参考：`hao.uisdc.com/ai/`、`ai-bot.cn`、`aigc.cn`

3. `template-media-portal.html`

- 适合媒体化导航站
- 强调热榜、专题、推荐位、运营位
- 参考：`amz123/ai`、`aigc.cn`

## 对当前仓库的结论

当前仓库不是没有模板，而是：

- 已有一套 `family-nav` / `root-home-site` 的默认风格
- 但还没有抽成“多套可切换模板”
- 也还没有把“搜索导航型 / 分类目录型 / 门户媒体型”分开

所以下一步最合理的不是重写一整套导航站，而是把这 3 套模板逐步接进 `family-nav` 生成器，变成可配置的 `layoutVariant`。
